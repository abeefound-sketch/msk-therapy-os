## 3. AUDIT DEFECT REMEDIATION RECORD

During milestone baseline verification, a latent defect was discovered and resolved:
- **Root Cause:** In [`msk_therapy_os/points.py:2170`](file:///D:/5Projects/msk-therapy-os/msk_therapy_os/points.py#L2170), reading the binary `.backup_hmac_key` applied `.strip()` to raw random bytes generated by `secrets.token_bytes(32)`. When random bytes ended in whitespace characters (`\n`, `\r`, `\x20`), the binary key was trimmed to 31 bytes, causing sporadic length assertions (62 chars instead of 64 hex chars).
- **Remediation:** Removed `.strip()` on raw binary bytes while adding hex validation logic for string files.
- **Verification:** All 12 tests in `tests/test_safe_sqlite_restore.py` and all 766 tests in the full suite now pass deterministically.
